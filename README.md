# jayrr.dev

Personal portfolio site for Jayrr, built with Next.js.

The component registry that used to live here moved to [standardsui.com](https://standardsui.com) ([Jayrr-Dev/standards-ui](https://github.com/Jayrr-Dev/standards-ui)). This repo keeps a copy of the Standard components in `components/standard` so the portfolio can use them.

## Develop

```bash
npm install
npm run dev
```

## Edit the content

All the text on the home page lives in `app/content.ts`: the intro, the projects and the links.

## Checks

```bash
npm run check
```
